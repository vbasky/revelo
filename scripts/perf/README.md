# Performance Comparison Config

This directory contains configuration for the Rust-native `revelo-bench`
developer tool. It intentionally does not contain Python, Node, Playwright or
browser automation scripts.

Generated benchmark outputs are written under `target/perf-investigation/` and
generated media fixtures under `target/perf-fixtures/`; neither directory should
be committed.

Required external tools for the full comparison:

- `hyperfine`
- `mediainfo`
- `ffmpeg`
- `ffprobe`

The WASM check additionally requires:

- a rustup-managed toolchain for this repository;
- `rustup target add wasm32-unknown-unknown`.

PNG table capture additionally needs an installed Chrome-compatible browser:

- Google Chrome
- Chromium
- Microsoft Edge

`revelo-bench` discovers common browser paths and `PATH` binaries, or accepts
`--chrome-path`. If no browser is available, JSON and HTML are still generated
and `results.json` records `table_png.status = "skipped"`.

## Entry Points

Run the full comparison from a manifest:

```sh
just bench-compare scripts/perf/manifest.example.json
```

Run the larger generated-only fixture matrix:

```sh
just bench-compare scripts/perf/manifest.extended.example.json
```

Write only sanitized JSON:

```sh
just bench-compare-json path/to/local-manifest.json
```

Regenerate HTML from existing JSON:

```sh
just bench-compare-table \
  target/perf-investigation/<run-id>/results.json
```

Regenerate HTML and PNG from existing JSON:

```sh
just bench-compare-png \
  target/perf-investigation/<run-id>/results.json
```

Run the evidence pipeline with one shared run id:

```sh
just bench-evidence path/to/local-manifest.json
```

Check the WASM feature graph:

```sh
just bench-wasm
```

Strict MediaInfo parity checks are intentionally separate from this performance
suite. Use the existing Rust `revelo-diff` XML harness when changing parser
output semantics.

## Manifest Schema

The manifest schema is `revelo_perf_manifest_v2`. Each case must contain
exactly one source:

- `synthetic`: generated by `revelo-bench generate-fixtures`;
- `path`: real local media, usually from a private or public corpus checkout.

Generated-only example:

```json
{
  "schema": "revelo_perf_manifest_v2",
  "settings": { "warmups": 2, "runs": 10 },
  "cases": [
    {
      "id": "synthetic-mp4-snv2-tail-389m",
      "label": "MP4 / SNV2 / moov tail / 389 MiB",
      "class": "synthetic",
      "container": "MP4",
      "codec": "H.264",
      "layout": "SNV2 brand, moov tail, sparse mdat",
      "source": "generated",
      "synthetic": {
        "kind": "mp4_snv2_tail",
        "size_bytes": 407896064
      }
    }
  ]
}
```

Real media example:

```json
{
  "schema": "revelo_perf_manifest_v2",
  "settings": { "warmups": 2, "runs": 10 },
  "cases": [
    {
      "id": "real-mp4-avc-local",
      "label": "MP4 / AVC / real local sample",
      "class": "real",
      "container": "MP4",
      "codec": "H.264",
      "layout": "real media",
      "source": "local private or public corpus label",
      "path": "local-media/not-committed/real-mp4-avc.mp4"
    }
  ]
}
```

The manifest can compare multiple Revelo binaries in the same run:

```json
{
  "schema": "revelo_perf_manifest_v2",
  "revelo_versions": [
    { "id": "revelo_0_4_6", "label": "Revelo 0.4.6", "path": "target/perf-tools/revelo-0.4.6" },
    { "id": "revelo_0_5_0", "label": "Revelo 0.5.0", "path": "target/perf-tools/revelo-0.5.0" },
    { "id": "revelo_0_5_1", "label": "Revelo 0.5.1", "path": "target/perf-tools/revelo-0.5.1" },
    { "id": "revelo_branch", "label": "Revelo branch", "path": "target/release/revelo" }
  ],
  "cases": [
    {
      "id": "synthetic-mp4-snv2-tail-389m",
      "label": "MP4 / SNV2 / moov tail / 389 MiB",
      "class": "synthetic",
      "container": "MP4",
      "synthetic": { "kind": "mp4_snv2_tail", "size_bytes": 407896064 }
    }
  ]
}
```

## Outputs

Default output layout:

```text
target/perf-investigation/<run-id>/
  results.json
  benchmark-table.html
  benchmark-table.css
  benchmark-table.png        # optional, when Chrome/Chromium/Edge is available

target/perf-fixtures/<run-id>/
  <generated synthetic media>
```

`results.json` records the measurement backend and environment:

```json
{
  "measurement_backend": {
    "name": "hyperfine",
    "required": true
  }
}
```

Real-media manifests may contain private paths. Sanitized outputs keep labels,
sizes, tool versions and aggregate timings, but not local manifest paths.
